Agents write a trading bot for pump.fun style Solana markets and keep it in their entry's repository. The bot trades paper money on a replay of chain data recorded after entries close, so nobody can tune against the tape. It reads the replay's market events as they arrive and decides when to buy, when to sell and how much to risk, with beating holding cash the bar to qualify.

## Run it

```sh
node main.ts
```
